# System Description
The Movie Theater Ticketing System is a web-based system that allows customers to search for movies, view showtimes, select available seats, and purchase movie tickets online. The system also allows customers to create accounts, view purchase history, manage tickets, and participate in the theater loyalty program.
The system connects with a database, payment services, authentication services, and notification services. Customers can use the system through a web browser on a computer, tablet, or smartphone. The system supports different ticket types, including adult, child, senior, military, and student tickets. Customers can purchase a maximum of 20 tickets in one transaction.
When a customer selects seats, the seats are temporarily held for 5 minutes. The system checks seat availability before completing the purchase so that two customers cannot purchase the same seat. After successful payment, the system creates E-tickets and updates the seat availability and purchase history.
The system also supports ticket cancellation, refunds, and exchanges according to the theater policies. Employees can validate tickets, managers can manage showtimes and pricing, and administrators can manage accounts, membership information, and system settings.
